# 우리 반 디지털 미술관

아이패드 한 대로 학생 활동지를 촬영하고, 아이패드 화면을 빔프로젝터에 미러링하여 공동 작품을 만드는 정적 웹앱입니다. 서버, 로그인, 유료 API가 필요 없습니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소(예: `sketch-museum`)를 만듭니다.
2. ZIP을 풀고 **안에 들어 있는 파일 전부**를 저장소 맨 위에 업로드합니다. `index.html`이 저장소 첫 화면에 보여야 합니다. ZIP 파일 자체만 올리거나 폴더째 한 단계 안에 넣으면 안 됩니다.
3. 저장소 `Settings → Pages → Build and deployment`에서 `Deploy from a branch`, `main`, `/(root)`를 선택하고 저장합니다.
4. 표시된 Pages 주소(`https://사용자명.github.io/sketch-museum/`)를 아이패드 Safari에서 엽니다.
5. 공유 → 홈 화면에 추가를 하면 앱처럼 실행할 수 있습니다. 아이패드를 AirPlay 또는 케이블로 빔프로젝터에 미러링합니다.

## 수업 흐름

- `배경 설정`에서 겨울 풍경 사진 또는 작품 이미지를 선택합니다.
- `작품 추가` → `카메라로 촬영` → 배경 제거 강도 확인 → 움직임 선택 → `작품 속에 넣기`.
- `작품 정리`에서 작품을 탭해 손가락으로 이동하고, 두 손가락으로 크기와 각도를 바꿉니다. 아래 메뉴에서 움직임, 앞뒤 순서, 삭제도 바꿀 수 있습니다.
- `전시 화면`을 누르면 도구가 숨겨집니다. 왼쪽 위 작은 버튼 또는 화면 두 번 탭으로 돌아옵니다.
- 각 작품은 `고정`, `흔들기`, `천천히 이동`, `떨어지기` 중에서 선택할 수 있습니다. 움직임은 천천히 반복됩니다. 편집 중에는 멈춥니다.

## 촬영 팁 및 한계

흰 종이만 화면에 가득 차게, 그림자 없이 촬영하세요. 종이 바깥의 책상이나 손이 많이 보이면 자동 배경 제거가 잘못될 수 있습니다. 흰색으로 그린 부분도 종이와 함께 사라질 수 있으므로 흰 표현은 외곽선을 그리거나 다른 색 종이에 작업한 이미지를 사용하세요. 손글씨도 그림처럼 처리됩니다. 결과가 이상하면 강도 슬라이더를 낮춰 다시 확인하세요.

학생 작품과 배경은 해당 아이패드 브라우저의 IndexedDB에 저장됩니다. 다른 아이패드와 자동 동기화되지 않으며 Safari 웹사이트 데이터 삭제나 개인 정보 보호 모드에서는 보존되지 않을 수 있습니다. 인터넷 없이 쓰려면 Pages 주소를 **온라인에서 한 번 열고** 홈 화면에 추가한 뒤, 수업 전에 비행기 모드에서 재실행을 확인하세요. GitHub Pages에 학생 작품 사진을 업로드하지 않습니다.

## 수업 전 2분 점검

1. 아이패드 Safari에서 배경을 설정합니다.
2. 테스트 그림을 촬영하고 배경 제거 결과를 확인합니다.
3. 움직임을 골라 추가하고, 이동·확대합니다.
4. 새로고침해 복원되는지 확인한 다음 테스트 작품을 삭제합니다.
5. 빔프로젝터 미러링과 전시 화면을 확인합니다.

코드 변경 위치: `index.html`의 `processImage()`에서 흰색 제거 로직과 강도 기본값(`id="threshold"`의 `value`)을 조정할 수 있습니다. 배경 이미지는 수업 중 `배경 설정`에서 선택합니다. 서버 측 동기화는 없으며 향후 저장 기능을 다른 서비스로 바꾸려면 `initDB`, `idbGet`, `idbSet`, `saveState`를 교체하면 됩니다.
